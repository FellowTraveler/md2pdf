# Decode QR Code On Screen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a hotkey-driven "Decode QR Code On Screen" service to md2pdf that captures a screen selection, decodes the QR code with zxing-cpp, copies the payload to the clipboard, and confirms with a notification.

**Architecture:** One new polyglot Python script `qr2clip` (same shape as `audio2md`/`md2audio`, runs in `~/.md2pdf-venv`) plus one new no-input Automator workflow. The existing install system's `*.workflow` glob handles list/install/update/remove; `install.sh` gets dependency gating and two fixes keyed on the workflow's own `serviceInputTypeIdentifier` so no-input services keep their hotkey and never become Shortcuts.

**Tech Stack:** Python 3 (stdlib + `zxing-cpp` 3.x + `Pillow`), bash, Automator `.workflow` plists, stdlib `unittest`.

**Spec:** `docs/plans/2026-09-20-qr2clip-design.md`

**Branch:** `feat/qr2clip` (already created). **Commits: never add a Co-Authored-By line.**

## Verified facts (do not re-derive)

- `zxingcpp.read_barcodes(PIL.Image) -> list`; each result has `.text`; returns `[]` when nothing is found (verified on zxing-cpp 3.1.1).
- `zxingcpp.create_barcode(text, zxingcpp.BarcodeFormat.QRCode)` + `zxingcpp.write_barcode_to_image(barcode, scale=8)` returns a buffer (`memoryview(...).shape == (h, w)`, format `B`). `write_barcode()` is deprecated — do not use it.
- The user's sample `samples/THE_TRUTH_ABOUT_WOMEN_NOT_LOSING_WEIGHT_AFTER_40_QR_POSTER.jpg` decodes to exactly `https://drodom.substack.com/p/the-truth-about-women-not-losing`.
- `CGPreflightScreenCaptureAccess()` is callable via `ctypes` from `/System/Library/Frameworks/CoreGraphics.framework/CoreGraphics`; it never prompts.
- `osascript -e 'on run argv' -e 'display notification (item 1 of argv) with title (item 2 of argv)' -e 'end run' MSG TITLE` keeps MSG literal. **QR payloads are untrusted input — never interpolate them into an AppleScript or shell string** (the `os.system(f"osascript ...")` pattern in `audio2md` must NOT be copied here).
- macOS stores a service hotkey as `key_equivalent` inside the `pbs NSServicesStatus` entry `"(null) - <menu name> - runWorkflowAsService"`. `install.sh`'s `defaults write pbs NSServicesStatus -dict-add` replaces that whole entry.
- All 12 existing workflows have `serviceInputTypeIdentifier` of `com.apple.Automator.fileSystemObject` or `...fileSystemObject.folder`. None is `com.apple.Automator.nothing`.
- `install.sh` is 499 lines; the project rule caps files at 500. Task 5 frees 73 lines before anything is added.
- **Never run `install.sh` or `uninstall.sh` non-interactively as a test.** `install.sh` runs `uninstall.sh` first, which deletes `~/.md2pdf-venv` and the user's installed services. The real install is a manual step the user performs (Task 8).

#!/bin/bash
# -*- mode: python -*-
''':'
exec "$HOME/.md2pdf-venv/bin/python3" "$0" "$@"
'''

import os
import sys

MSG_NOT_FOUND = "No QR code found in that selection"
MSG_NO_SUCH_FILE = "qr2clip: no such file: {path}"
MSG_CANNOT_READ_IMAGE = "qr2clip: cannot read image: {path}"
USAGE = """Usage:
  qr2clip            Drag-select a QR code on screen; the payload is copied to the clipboard
  qr2clip <image>    Decode a QR code from an image file and print the payload"""


def decode_qr(image_path):
    """Return the text of the first QR/barcode found in the image, or None."""
    import zxingcpp
    from PIL import Image
    results = zxingcpp.read_barcodes(Image.open(image_path))
    return results[0].text if results else None


def decode_file(image_path):
    if not os.path.isfile(image_path):
        print(MSG_NO_SUCH_FILE.format(path=image_path), file=sys.stderr)
        return 1
    try:
        payload = decode_qr(image_path)
    except OSError:  # PIL.UnidentifiedImageError is an OSError
        print(MSG_CANNOT_READ_IMAGE.format(path=image_path), file=sys.stderr)
        return 1
    if payload is None:
        print(MSG_NOT_FOUND, file=sys.stderr)
        return 1
    print(payload)
    return 0


def main():
    arguments = sys.argv[1:]
    if len(arguments) == 1 and arguments[0] not in ("-h", "--help"):
        return decode_file(arguments[0])
    print(USAGE)
    return 0 if arguments in (["-h"], ["--help"]) else 2


if __name__ == "__main__":
    sys.exit(main())
```

        self.capture_paths = []

        self.copy_to_clipboard = self.patch("copy_to_clipboard")
        self.open_settings = self.patch("open_screen_recording_settings")

        patcher = mock.patch.object(qr2clip, function_name, **kwargs)
        self.addCleanup(patcher.stop)
        return patcher.start()

    def fake_capture(self, fixture_name):
        """Stand-in for capture_selection: fixture_name=None simulates an empty capture."""
        def capture(capture_path):
            self.capture_paths.append(capture_path)
            if fixture_name is None:
                return False

import ctypes
import importlib.util
import os
import subprocess
import sys
import tempfile

NOTIFICATION_TITLE = "Decode QR Code"
PREVIEW_LENGTH = 80
CAPTURE_SUFFIX = ".png"
DECODER_MODULE = "zxingcpp"

SCREENCAPTURE_BIN = "/usr/sbin/screencapture"
PBCOPY_BIN = "/usr/bin/pbcopy"
OSASCRIPT_BIN = "/usr/bin/osascript"
OPEN_BIN = "/usr/bin/open"
COREGRAPHICS_LIB = "/System/Library/Frameworks/CoreGraphics.framework/CoreGraphics"
SCREEN_RECORDING_SETTINGS_URL = (
    "x-apple.systempreferences:com.apple.preference.security?Privacy_ScreenCapture"
)
# The message and title are passed as argv so untrusted QR text is never parsed as AppleScript.
NOTIFY_APPLESCRIPT = (
    "on run argv",
    "display notification (item 1 of argv) with title (item 2 of argv)",
    "end run",
)

MSG_CANCELLED = "Capture cancelled"
MSG_PERMISSION = "Screen Recording permission needed — opening System Settings"
MSG_NOT_FOUND = "No QR code found in that selection"
MSG_COPIED = "QR code copied: {preview}"
MSG_MISSING_DECODER = "zxing-cpp is not installed — re-run md2pdf's install.sh"
MSG_NO_SUCH_FILE = "qr2clip: no such file: {path}"
MSG_CANNOT_READ_IMAGE = "qr2clip: cannot read image: {path}"
USAGE = """Usage:
  qr2clip            Drag-select a QR code on screen; the payload is copied to the clipboard
  qr2clip <image>    Decode a QR code from an image file and print the payload"""


def notify(message):
    command = [OSASCRIPT_BIN]
    for line in NOTIFY_APPLESCRIPT:
        command += ["-e", line]
    subprocess.run(command + [message, NOTIFICATION_TITLE], check=False)


def copy_to_clipboard(text):
    subprocess.run([PBCOPY_BIN], input=text.encode("utf-8"), check=True)


def open_screen_recording_settings():
    subprocess.run([OPEN_BIN, SCREEN_RECORDING_SETTINGS_URL], check=False)


def decoder_available():
    return importlib.util.find_spec(DECODER_MODULE) is not None


def has_screen_capture_access():
    """Passive Screen Recording (TCC) check; never triggers the system prompt."""
    core_graphics = ctypes.cdll.LoadLibrary(COREGRAPHICS_LIB)
    core_graphics.CGPreflightScreenCaptureAccess.restype = ctypes.c_bool
    return bool(core_graphics.CGPreflightScreenCaptureAccess())


def capture_selection(capture_path):
    """Interactive drag-to-select capture. False means nothing was captured
    (user pressed Esc, or Screen Recording permission is missing)."""
    subprocess.run([SCREENCAPTURE_BIN, "-i", capture_path], check=False)
    return os.path.isfile(capture_path) and os.path.getsize(capture_path) > 0


def preview_of(payload):
    if len(payload) <= PREVIEW_LENGTH:
        return payload
    return payload[:PREVIEW_LENGTH] + "…"
```

Add `scan_screen` directly above `def main():`:

```python
def scan_screen():
    if not decoder_available():
        notify(MSG_MISSING_DECODER)
        return 1
    descriptor, capture_path = tempfile.mkstemp(suffix=CAPTURE_SUFFIX)
    os.close(descriptor)
    try:
        if not capture_selection(capture_path):
            # An empty capture is a capture failure, never "no QR code found".
            if has_screen_capture_access():
                notify(MSG_CANCELLED)
            else:
                notify(MSG_PERMISSION)
                open_screen_recording_settings()
            return 1
        payload = decode_qr(capture_path)
        if payload is None:
            notify(MSG_NOT_FOUND)
            return 1
        copy_to_clipboard(payload)
        notify(MSG_COPIED.format(preview=preview_of(payload)))
        return 0
    finally:
        os.remove(capture_path)
```

import plistlib
import unittest
from pathlib import Path

REPO_ROOT = Path(__file__).resolve().parent.parent
WORKFLOW_NAME = "Decode QR Code On Screen"
NO_INPUT_TYPE = "com.apple.Automator.nothing"


def load_plist(workflow_dir, file_name):
    with open(workflow_dir / "Contents" / file_name, "rb") as plist_file:
        return plistlib.load(plist_file)


class QrWorkflowTests(unittest.TestCase):
    def setUp(self):
        self.workflow_dir = REPO_ROOT / f"{WORKFLOW_NAME}.workflow"

    def test_service_menu_name_matches_existing_hotkey_binding(self):
        service = load_plist(self.workflow_dir, "Info.plist")["NSServices"][0]
        self.assertEqual(service["NSMenuItem"]["default"], WORKFLOW_NAME)
        self.assertEqual(service["NSMessage"], "runWorkflowAsService")

    def test_service_takes_no_input_and_is_not_limited_to_finder(self):
        info = load_plist(self.workflow_dir, "Info.plist")
        service = info["NSServices"][0]
        self.assertNotIn("NSSendTypes", service)
        self.assertNotIn("NSRequiredContext", service)
        self.assertNotIn("ShortcutInputClasses", info)
        metadata = load_plist(self.workflow_dir, "document.wflow")["workflowMetaData"]
        self.assertEqual(metadata["serviceInputTypeIdentifier"], NO_INPUT_TYPE)
        self.assertNotIn("serviceApplicationBundleID", metadata)

    def test_workflow_runs_qr2clip(self):
        document = load_plist(self.workflow_dir, "document.wflow")
        command = document["actions"][0]["action"]["ActionParameters"]["COMMAND_STRING"]
        self.assertIn('export PATH="$HOME/bin:', command)
        self.assertEqual(command.strip().splitlines()[-1], "qr2clip")

    def test_it_is_the_only_no_input_workflow(self):
        """install.sh skips the pbs write and Shortcut generation for no-input
        workflows; this guards every file-based workflow from being skipped."""
        no_input_workflows = [
            workflow_dir.name
            for workflow_dir in sorted(REPO_ROOT.glob("*.workflow"))
            if load_plist(workflow_dir, "document.wflow")["workflowMetaData"][
                "serviceInputTypeIdentifier"
            ] == NO_INPUT_TYPE
        ]
        self.assertEqual(no_input_workflows, [f"{WORKFLOW_NAME}.workflow"])


if __name__ == "__main__":
    unittest.main()

````markdown
## Decode QR Code On Screen

Press a hotkey, drag a box around a QR code anywhere on screen — a browser tab, a PDF, a photo — and the decoded text is copied to your clipboard. A notification confirms what was copied; nothing is opened automatically.

Decoding uses [zxing-cpp](https://github.com/zxing-cpp/zxing-cpp), which reads QR codes that have a logo or image in the center (a style `zbar` often fails on).

```bash
qr2clip                # drag-select on screen -> clipboard
qr2clip poster.png     # decode an image file -> stdout
```

### Setup

1. Select **Decode QR Code On Screen** when running `./install.sh`. It installs as a Service that works in every app (it is not a Finder right-click action and has no Shortcuts-app version).
2. Bind a hotkey: **System Settings → Keyboard → Keyboard Shortcuts → Services → General → Decode QR Code On Screen**. The hotkey survives reinstalls.
3. The first time you use it, grant **Screen Recording** permission when System Settings opens, then try again.

### Troubleshooting: "Screen Recording permission needed"

Screen capture is gated by a system-level privacy permission (`kTCCServiceScreenCapture`). The process that launches the capture needs its own explicit grant under **System Settings → Privacy & Security → Screen Recording** — being an automation tool does not grant it. Without it, macOS shows no prompt and no error: the capture simply comes back empty. `qr2clip` detects this and tells you, rather than reporting "no QR code found".

**System Audio Recording** is a separate, adjacent permission. Having it does not enable screen capture.

| Notification | Meaning |
|---|---|
| QR code copied: … | Success — paste anywhere |
| No QR code found in that selection | The capture worked, but no code could be read. Select the whole code with a little margin. |
| Capture cancelled | You pressed Esc |
| Screen Recording permission needed | The capture was blocked; grant the permission and retry |
````
